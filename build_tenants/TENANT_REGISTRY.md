# Tenant Registry

This registry records project-owned realization tenants for the shared
`odd_trading_eval` specification.

| Tenant | Kind | Status | Scope |
| --- | --- | --- | --- |
| `odd_trading_eval/typescript` | realization | candidate | TypeScript semantic/control tenant for the first contextual trade-algebra slice; CPU reference compute first, external numerical adapters later |

No tenant is active. Candidate status does not authorize implementation or
create a second product-definition surface.

Activation requires closure of `GOALS.md` G-001 through G-003, ratified
requirements, tenant design, public GTL carrier definitions, ABG boundaries, a
pinned CDM adapter contract, and the semantic-plumbing proof fixture described
in `specification/PRODUCT.md`.
